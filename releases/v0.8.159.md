# HyperFrames v0.8.159

Released on 2026-10-14.

`check` and `snapshot` now work in sandboxes that refuse to listen on localhost. `snapshot --keep` lets you redo one still without losing the others.

## Features

- **CLI:** `snapshot --keep` redoes one still and leaves the others ([c0636d017f6](https://github.com/heygen-com/hyperframes/commit/c0636d017f68073522ab8eeb6cc24a2d3993b656), [#5605](https://github.com/heygen-com/hyperframes/pull/5605)). It adds to the output folder instead of clearing it and names each still for its time, such as `at-1.5s.png`.

## Fixes

- **Core:** A render's first frame shows each scene's starting state ([8c00ebad80c](https://github.com/heygen-com/hyperframes/commit/8c00ebad80c634f607e3a5283f8a0aa73e35f1dd), [#5614](https://github.com/heygen-com/hyperframes/pull/5614)).
- **CLI:** `check` and `snapshot` run where a sandbox refuses to listen on localhost ([71595dd8201](https://github.com/heygen-com/hyperframes/commit/71595dd82012314f353d1237f50da0fad7639817), [#5618](https://github.com/heygen-com/hyperframes/pull/5618)).
- **CLI:** The GPU check uses the same pipe as the render, so a sandboxed `check` no longer waits 120 s ([6c89decb0dd](https://github.com/heygen-com/hyperframes/commit/6c89decb0ddbac7c30a7dca6d947f945ebd58c0e), [#5622](https://github.com/heygen-com/hyperframes/pull/5622)).
- **CLI:** A long video conversion in `init` never stalls on ffmpeg's own log ([b14a4564716](https://github.com/heygen-com/hyperframes/commit/b14a45647166e60e2e51dc018ccb1bb7331003a2), [#5616](https://github.com/heygen-com/hyperframes/pull/5616)).

## Internal

- A stalled history fetch in change detection is retried instead of failing the run ([cd87cf11106](https://github.com/heygen-com/hyperframes/commit/cd87cf11106985c6222723f5b391723882691d6c), [#5615](https://github.com/heygen-com/hyperframes/pull/5615)).
